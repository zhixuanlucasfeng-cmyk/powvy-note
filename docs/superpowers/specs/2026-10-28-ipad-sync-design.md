# Powvy Note：iPad 与 Mac 账号同步

## 已确认的需求
- iPad 与现有 Mac 版自动同步同一份笔记。
- 登录只使用用户名和密码，不强制邮箱、手机号或验证码。
- 保留 Markdown、待办勾选及现有标签。

## 建议实现（待确认）
- iPad 使用适配触屏的 PWA，通过 Safari 添加到主屏幕；Mac 保留现有原生悬浮窗口。
- 首版供本人使用：通过受保护的一次性初始化创建账号，完成后关闭初始化入口，避免他人抢先注册；不默认开放公众注册。Mac 与 iPad 登录同一账号。
- 服务端建议使用 Cloudflare Workers + D1，网页版与 API 同源部署；部署前确认账号权限和实际费用，不默认购买服务。
- 复用 windows/md.js 的 Markdown 和标签处理；不改变已有 Mac 笔记格式。
- Mac 首次登录后展示导入数量，由用户在应用内点击同步现有笔记；先备份，再上传，避免把已有私人笔记静默传到云端。
- 服务端用用户身份隔离数据；只存加盐密码派生值，限制登录尝试。网页版使用 HttpOnly 会话 cookie，Mac 会话凭证放系统 Keychain。全程 HTTPS。
- 不要求邮箱，因此初次设置提供离线恢复码。忘记密码时用恢复码重设；登录成功后可更改密码。

## 同步行为
- 保存先落到本机，再在联网时同步；明确显示待同步、已同步、离线或失败。
- 笔记使用稳定 ID 与服务端版本号。已有文件名保持不变，映射信息单独保存。
- 同一笔记在两台设备同时修改时，不按最后时间直接覆盖：保留冲突副本并提示用户选择。
- 删除用服务端删除标记传播；旧设备离线后上线不能把已删内容自动恢复。
- 用户退出登录前提示尚未同步的修改；不同账号的离线缓存分开，不混用。
- 自动同步限应用运行期间。iPad 后台受到系统限制，回到应用后继续同步，不承诺后台实时推送。

## 验收
- 同一账号在 iPad 与 Mac 新建、编辑、勾选待办、删除后，另一端可同步。
- 断网编辑、恢复网络、应用重新打开后，内容不会丢失。
- 并发修改产生可见冲突副本；不同账号不能读取或修改彼此笔记。
- 用户名密码登录、退出、限流与恢复码流程经过测试。
- 使用临时笔记目录和测试账号，不对用户真实笔记执行破坏性测试。
- 本地和测试环境验证后，再部署 HTTPS 网址并提供 Mac 更新安装包；不自动替换正在运行的 Mac 应用。

## 本轮不包含
Windows 同步、多人协作、富文本编辑、附件同步和 App Store 上架。
