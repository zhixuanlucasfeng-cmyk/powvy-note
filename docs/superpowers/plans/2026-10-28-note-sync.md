# Powvy Note Sync Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Working username/password notes on iPad/iPhone, synchronized with the existing Mac app.
**Architecture:** Same-origin static PWA + Cloudflare Worker/D1; per-note compare-and-swap revisions. Mac keeps Markdown files and stores sync metadata separately; Keychain holds its session.
**Tech Stack:** Vanilla JavaScript, Workers Web Crypto, D1 SQLite, Swift Foundation/SwiftUI/Security.
**Spec:** ../specs/2026-10-28-ipad-sync-design.md

## Global Constraints
No mandatory email/phone. Preserve existing local notes. No real-note destructive tests. HTTPS deployment; do not buy resources. No background iOS sync guarantee. User explicitly requested execution: implement inline without another approval gate.

## Review Focus
- Concurrent edits and delete/edit races must preserve a conflict copy (Tasks 2/3).
- Lost responses must be safely retriable (Task 1).
- Account changes must not mix cached notes or auto-upload old content (Tasks 2/3).
- Offline writes must survive reload and pending edits must block logout (Tasks 2/3).
- Setup and recovery must not allow takeover; login/session endpoints must be rate-limited and same-origin (Task 1).

## Task 1: Authenticated sync API
Files: cloud/worker.js, cloud/schema.sql, cloud/wrangler.jsonc, package.json, tests/api.test.mjs.
Interfaces: POST /api/setup {username,password,recoveryCode} with X-Setup-Key; POST /api/login {username,password,native?}; POST /api/recover {username,password,recoveryCode}; GET /api/me; POST /api/logout; POST /api/password {oldPassword,password}; GET /api/notes; PUT /api/notes/:id {text,deleted,baseVersion}. Return {note} or 409 {note}; auth response {user:{id,username},token?}. Native token only if native:true and request has no Origin; browser uses HttpOnly cookie.
- [x] Write integration checks: setup gate, wrong password, foreign-origin denial, sessions, CAS/retry, isolation, recovery rotation.
- [x] Run and observe missing implementation failure; implement SQL atomic writes and Worker validation; run green with local D1.
