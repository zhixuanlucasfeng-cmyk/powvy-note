Powvy Note 安装说明（Windows 10 / 11，64 位）

1. 双击 PowvyNote-Setup-0.3.1.exe，会自动装好并打开，不用选目录。
2. 第一次可能弹出蓝色的“Windows 已保护你的电脑”（这个 app 没买代码签名证书），
   点「更多信息」→「仍要运行」。

用法
- 鼠标移到屏幕最上方正中间（那条黑色小条）就会展开；移开自动收回。
- 右上角 ✕ 或 Esc：收起（程序还在后台）。Ctrl+N 新建笔记。
- 划掉（表示做完）：选中一段文字，点右上角带横线的 S 按钮或按 Ctrl+Shift+X；不选文字就划掉光标所在的整行。再点一次取消。
- 复制粘贴：Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A / Ctrl+Z 都能用，右键也有菜单。
- 标签：输入 [ 会弹出 To do / Homework / Test / Appointment / Class，点一下或按 1–5 插入。
  Test、Appointment 和 Class 插入后光标停在括号里，直接输日期或科目，比如 [test 10/25]、[appointment 周五 3pm]、[class Maths 9am]，按回车或 Tab 跳出括号。
- 右下角托盘里的便签图标：左键打开；右键菜单有 开机自启（Open at Login）/ 退出。
  图标被收进 ^ 里的话，可以把它拖到任务栏上常驻。
- 退出后想再打开：开始菜单里搜 Powvy Note。
- 笔记都是 .md 文件，存在 %APPDATA%\Powvy Note\（在资源管理器地址栏输入这个路径即可打开）。
- 卸载：设置 → 应用 → Powvy Note → 卸载。笔记文件会保留。
